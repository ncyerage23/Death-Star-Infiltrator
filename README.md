# Death-Star-Infiltrator


Death Star-based stealth precision platformer game. From scratch!

## This Branch
Doing some refactoring and fixes in the engine module, before I get back to doing the editors. 
- File documentation (nymg, nymap, tiles, tilemaps, bigmaps)
- Tilemap generator program (taking a bunch of tiles and combining them into one big file)
- Map renderer module (a module specifically for drawing loaded maps)
- Bigmap generator program (same as tilemap generator, but for levels)
- Overall engine/canvas module fixes and additions (time module, better font thing, more keys, and just overall fixes)

So yeah. Just knock these out one at a time, and then see what happens. They're mostly pretty easy, anyway. 
I think.
