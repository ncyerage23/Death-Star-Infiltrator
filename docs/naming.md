# Death Star -- module naming conventions
### Nathaniel Yerage -- 10/5/26


I want to keep things easily differentiable, so it's easy to know what module/subsystem is for what. 
So, starting now, I'm going to use function prefixes (and file prefixes) for each module. 

The core and canvas modules will get it too, eventually, but those are already made and it'll be annoying
to change everything. I'll get to it when I refactor them. 

## Modules and their prefixes
**File:** f_
**Data:** d_
**Renderer:** r_

That's all I have for now, but yeah.
